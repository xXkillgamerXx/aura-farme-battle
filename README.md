# aura-farme-battle

Prototipo web de **batallas de farmeo de aura** (Vue 3 + Three.js).

## Jugar online

Cuando GitHub Pages esté activo:

**https://xxkillgamerxx.github.io/aura-farme-battle/**

## Controles

| Tecla | Acción |
|--------|--------|
| ← → ↑ ↓ / WASD | Mover |
| Q / E | Cambiar move |
| SPACE | Atacar / timing / continuar |

## Correr en local

```bash
git clone https://github.com/xXkillgamerXx/aura-farme-battle.git
cd aura-farme-battle
npm install
npm run dev
```

Abre la URL que muestre Vite (normalmente http://localhost:5173/).
